# **需求背景**

## **需求现状：**

  智能财务的企业客户在费用标准-标准设置-控制方式配置时无法按车型分别配置补贴规则，企业客户需要按照油车和电车分别配置

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/626b96cf-19f0-4130-8b37-fc1d5e6c7115.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=YshSyH2aJr998jKHNhXpBRZC98U%3D "")

##   **客户预期**

  企业可以通过【按车型分别计算】去配置油车和电车的不同补贴标准



# **功能清单**

| 模块 | 功能点 | 备注 |
|------|---------|------|
| 控制方式-按车型分别计算 | 增加【按车型分别计算】配置功能，满足用户按照车型分别设置补贴标准 |  |
| 费用标准 | 增加【按车型分别计算】配置功能 |  |

# **需求详情**

## 3.1 设置-辅助设置增加「车型设置」

![画布 168.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/63dead32-e73e-4864-8367-40ca86a4ab07.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=VgAbgwONqCEDimR4mwfG57HbKYY%3D "")

**功能说明**：
- 批量停用：支持勾选多个辅助核算项批量停用，逻辑与「辅助核算设置」配置的「批量停用」功能相同
- 批量添加：支持表格导入的方式批量添加「辅助核算」，功能逻辑与「辅助核算设置」配置的「批量添加」功能相同
- 单个添加：支持单个新增「辅助核算」，功能逻辑与「辅助核算设置」配置的「单个添加」功能相同
- 批量修改：支持批量修改「可见范围」，功能逻辑与「辅助核算设置」配置的「批量修改」功能相同
    - ![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/3e3cb19c-d0d6-4e7f-bfc7-178d6775ba21.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=ujokyMwsoQPakKefPona5PRh9HA%3D "")
- 导出：支持将所有「已启用」辅助核算项导出至「财务助手」消息并下载导出的文件，功能逻辑与「辅助核算设置」配置的「导出」功能相同
- 设置：支持控制「车型辅助核算」的字段在添加/编辑时是否显示隐藏和是否必填，可以快速「恢复默认设置」
- 显示未启用：默认不勾选，勾选后显示未启用的「车型辅助核算」
- 支持编辑，启用和停用辅助核算
- 支持通过车型名称和车型编码搜索
- 存量用户和新用户更新刷新出「车型设置」的辅助核算

## 3.2 费用标准-增加【按车型分别计算】配置功能

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/75b2feb4-d9d7-4b07-b49a-36d39bd2ab9a.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=wMlTs4RH5viuQKi2tjMjarcDV9Q%3D "")

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/c73eaf66-1efe-4f41-8c1b-6d2978e1c826.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=%2B4Paecuhm4z9pd%2BzXqDI%2BiMXTgw%3D "")

**位置**：预算费控 → 费用标准 → 标准设置 → 控制方式

**配置项**

| 档位 | 说明 |
|------|------|
| 按车型分别计算 | 不同车型不同标准：油车/电车（新增） |

**功能说明**：
- 默认「按车型统一计算」，存量保持不变
- 切换为「按车型分别计算」后，显示「车型设置」的配置项，默认为空，为空视为全选
- 点击「车型」弹出“选择辅助核算”弹窗，选择「车型设置」中的辅助核算项，支持多选
- 切换「控制方式」时，原有配置清空
- 车型中选中的「车型」与“里程补贴”费用中「车型」做匹配，匹配成功则规则生效

## 3.4 里程补贴定位打卡-增加选择车型（油车/电车）和里程信息生成的费用中带入车型信息

**位置：**智能财务-随手记-里程补贴-选择车型-打卡定位

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/5e0e4b16-420e-4d47-9cec-95fb52b51d7e.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=BEmudRPjgOu%2BqueY3T3ogIcTHBc%3D "")![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/b3a4b641-0f6f-4028-b7c1-0305f2f72bc6.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=GvPV4vIC%2F1Gl73gRuhzzt8F%2FQ2E%3D "")![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/6b7abb67-d59d-4c87-ac10-2ff66bfd6227.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=Gu9kW3cZ3nPqHgSjGi3zjknZ%2FHk%3D "")

![画布 75 Copy.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5byVkKMLlxo/img/60c641c6-df72-4e59-86dc-1b1ed4a46b81.png?Expires=1787725010&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=vDfJlV%2BqmpFoUgYRq%2FRaJKUprRc%3D "")


- 里程补贴打卡定位界面支持选择车型，车型可选来自辅助核算设置-「车型设置」，仅单选
- 选中某车型后，才可开始打卡定位，若未选择车型点击“记录”，提示“选择任一车型后才可开始打卡定位”
- 当前打卡行程未结束时，不允许切换车型；开始新的打卡行程前，可以切换车型
- 打卡行程结束后生成随手记费用，打卡行程信息生成“里程补贴”费用，本次生成的费用金额由配置的费用标准规则自动计算，后续使用该费用去报销

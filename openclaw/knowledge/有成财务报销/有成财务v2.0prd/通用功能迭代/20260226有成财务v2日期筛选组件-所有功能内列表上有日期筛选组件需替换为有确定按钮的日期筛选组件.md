# **1\. 需求背景**

列表内数据量过大时，用户使用现有日期筛选范围选择过大时，数据刷新会很慢，且筛选误操作会一直刷新；客户南羽集团有限公司要求日期范围选择后，通过“确定”按钮控制是否提交筛选条件；

# **3\. 需求详情**

日期范围筛选组件效果如图：

![画布 6.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/XNkOM5jjY5GGmOY7/img/06ccfbef-3f2b-48a0-abec-68ac7295d2d0.png?Expires=1787119998&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=qaa66DcsuyqqYn2yuyABhpxCeDM%3D "")


1. 图1处通过“确定”按钮提交条件，点击组件外侧或“取消”，关闭筛选组件，还原之前选择的日期；直接使用ant design组件；
2. 日期范围组件涉及优化的功能页面为：【凭证-凭证附件】【凭证-凭证汇总表】【流水账-日记账】【流水账-资金报表】【流水账-利润表】【基础设置-操作日志】

## 1\. 需求背景

### 1.1 需求描述

财务人员需要在不同公司账套之间迁移常用凭证数据，以及批量创建常用凭证。当前常用凭证功能仅支持单条手动创建，不支持批量导入和导出，导致多账套场景下重复录入工作量大。

本次需求在常用凭证功能中增加**导入**和**导出**能力，支持Excel批量操作。导入模板参照有成财务凭证导入模板的规范样式设计，字段覆盖常用凭证实际保存内容。

**重要约束：不同账套的会计科目设置可能不同，跨账套导入时需人工核对科目映射关系，系统不做自动科目映射。**

### 1.2 需求背景
- **需求方**：财务人员
- **现状问题**： 
    - 常用凭证仅支持单条手动创建，无法批量导入
    - 无法导出常用凭证数据，跨账套迁移需手动重建
    - 集团型企业多账套场景下，相同常用凭证需重复录入
- **解决思路**：在常用凭证功能中增加导入导出能力，支持Excel批量操作和跨账套数据迁移

**业务流程**
```plain
财务人员整理常用凭证清单
↓
使用导入模板批量创建常用凭证
↓
或导出已有常用凭证 → 在其他账套导入使用

```

## 2\. 功能现状

**功能位置**：基础设置 → 常用凭证

**现有功能**：
- 常用凭证列表展示（字段：序号、类型、名称、操作）
- 新增/编辑常用凭证（单条），包含：类型、名称、摘要、会计科目、借方金额、贷方金额
- 录入凭证时可调用常用凭证
- 录入凭证时可保存为常用凭证

**当前缺失能力**：
- 常用凭证导出功能
- 常用凭证批量导入功能
- 跨账套数据迁移能力

**导出文件格式**
- 文件名：`常用凭证_导出_YYYYMMDD_HHMMSS.xlsx`

**导入逻辑**
1. **数据校验**
    - 类型、名称、摘要、科目代码、科目名称 为必填项，为空时该行导入失败
    - 科目代码须为系统中存在的科目，不存在时该行导入失败
    - 科目名称须与编码匹配，不匹配时该行导入失败
    - 借方金额和贷方金额不能同时为空（至少有一个有值）
    - 借方金额和贷方金额不能同时有值（只能借方或贷方）
    - 金额字段须为文本格式或数值格式，包含非数字字符时该行导入失败
2. **类型处理**
    - 类型不存在时，自动创建新类型
    - 类型已存在时，使用已有类型
    - 类型名称在系统内不可重复（如已存在同名类型则直接使用）
3. **常用凭证处理**
    - 每一行数据作为一条常用凭证的一条分录
    - 同一"类型\+名称"的多行数据，导入为同一条常用凭证的多个分录
    - **名称支持重复**：系统不做"同类型下名称不可重复"的拦截
4. **科目校验**
    - 校验科目编码是否存在
    - 校验科目名称是否与编码匹配
    - 校验科目是否允许用于凭证（非末级科目等校验）
5. **错误处理**
    - 校验不通过时，**仅阻断错误行，正确行正常导入**
    - 导入完成后返回结果提示：成功导入XX条分录（XX条常用凭证），失败YY行
    - 提供错误文件下载，错误文件中标识每行错误原因
    - 用户修正后可重新导入

### 3.3 逻辑互斥与边界处理

**边界情况处理**

| **边界场景** | **触发条件** | **处理方案** |
|----------------|----------------|----------------|
| 类型不存在 | 导入的类型在系统中不存在 | 自动创建新类型，类型名称为导入值 |
| 名称重复 | 同一类型下名称重复 | **不拦截**，允许存在同名常用凭证 |
| 科目不存在 | 会计科目编码不存在 | 该行导入失败，提示"科目编码不存在" |
| 科目不匹配 | 编码和名称不匹配 | 该行导入失败，提示"科目名称与编码不匹配" |
| 金额校验 | 借贷方同时有值或同时为空 | 该行导入失败，提示"借方金额和贷方金额不能同时为空或同时有值" |
| 跨账套科目不一致 | 源账套和目标账套科目设置不同 | **严格校验**：目标账套科目编码不存在时，该行导入失败，需用户手动调整科目映射后重新导入 |
| 科目非末级 | 导入的科目不是末级科目 | 该行导入失败，提示"会计科目须为末级科目" |
| 模板列缺失 | 使用错误模板导入 | 整批阻断，提示"导入模板格式不正确，请下载标准模板" |
| 空行处理 | 导入文件包含空行 | 跳过空行，不报错 |
| 金额格式 | 金额包含非数字字符 | 该行导入失败，提示"金额格式不正确" |
| 文件格式 | 上传非 .xls / .xlsx 文件 | 整批阻断，提示"仅支持 .xls 和 .xlsx 格式的文件" |

**与其他功能的兼容性**

| **相关功能** | **交互关系** | **处理方案** |
|----------------|----------------|----------------|
| 录入凭证-常用凭证 | 数据读取 | 导入的常用凭证在录入凭证页面可正常选择使用 |
| 录入凭证-保存为常用凭证 | 数据写入 | 保存为常用凭证功能不受影响 |
| 会计科目管理 | 数据校验 | 导入时校验科目是否存在、是否末级 |
| 类型管理 | 数据写入 | 导入时自动创建不存在的类型 |
| **跨账套科目映射** | **关键约束** | **不同账套科目设置可能不同，导入前需人工核对科目映射关系，系统不做自动科目映射** |

**存量数据处理**
- 导入为新增操作，不影响已存在的常用凭证数据
- 暂不支持通过导入更新已有常用凭证

## 附录

**A. 典型使用场景**

场景：集团型企业，总公司已维护好常用凭证，需要同步到分公司账套

操作步骤：
1. 总公司财务进入基础设置 → 常用凭证
2. 点击"导出"，下载常用凭证数据
3. **导出分公司科目表，与总公司科目表核对编码一致性**
4. **如科目编码不一致，手动调整导入文件中的科目编码**
5. 分公司财务登录分公司账套
6. 进入基础设置 → 常用凭证 → 导入
7. 上传调整后的文件，完成导入
8. 导入失败时，下载错误文件查看科目不匹配项，修正后重新导入

结果：实现常用凭证的跨账套迁移（需人工处理科目映射）

**B. 导入模板示例**
```plain
| 类型 | 名称 | 摘要 | 科目代码 | 科目名称 | 借方金额 | 贷方金额 |
| 日常支出 | 报销差旅费 | 报销差旅费 | 520106 | 管理费用_差旅费 | 10000 | |
| 日常支出 | 报销差旅费 | 报销差旅费 | 1002 | 银行存款 | | 10000 |
| 工资 | 计提工资 | 计提工资 | 520103 | 管理费用_工资 | 50000 | |
| 工资 | 计提工资 | 计提工资 | 2211 | 应付职工薪酬 | | 50000 |

```

说明：
- 第1、2行为同一条常用凭证（日常支出-报销差旅费），包含两个分录
- 第3、4行为同一条常用凭证（工资-计提工资），包含两个分录
- 借方金额和贷方金额只能有一个有值

**C. 跨账套导入注意事项**

由于不同账套的会计科目设置可能存在差异，跨账套导入常用凭证时需注意：
1. **科目编码核对**
    - 导出后，先核对源账套和目标账套的科目编码是否一致
    - 如不一致，需手动调整导入文件中的科目编码和名称
2. **科目映射建议**
    - 建议在导入前，先导出目标账套的科目表作为对照
    - 建立源账套到目标账套的科目映射关系
    - 手动修改导入文件中的科目编码后，再执行导入
3. **系统行为**
    - 系统**不做自动科目映射**，严格按编码匹配
    - 编码不存在时，该行数据导入失败
    - 失败数据可在错误文件中查看，修正后可重新导入
4. **最佳实践**
    - 集团型企业建议统一会计科目编码体系
    - 如无法统一，建立科目对照表作为中间映射层
    - 大批量迁移前，建议先导入少量数据验证科目匹配情况

**D. 字段校验规则**

| **字段** | **必填** | **校验规则** |
|----------|----------|----------------|
| 类型 | 是 | 保持产品原逻辑，不存在时自动创建 |
| 名称 | 是 | 保持产品原逻辑，**允许重复** |
| 摘要 | 是 | 保持产品原逻辑 |
| 科目代码 | 是 | 须为系统中存在的科目编码，文本格式 |
| 科目名称 | 是 | 须与编码匹配 |
| 借方金额 | 否 | 数值，精度2位小数，与贷方金额互斥 |
| 贷方金额 | 否 | 数值，精度2位小数，与借方金额互斥 |

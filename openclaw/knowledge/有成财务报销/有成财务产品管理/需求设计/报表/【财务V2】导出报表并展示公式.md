# **4\. 需求详情**

### **4.1资产负债表**

#### **4.1.1按科目统计**

右上角导出功能，进行调整。点击出现下拉选项
1. 直接导出：原本的导出逻辑，不做调整
2. 导出公式：在导出数据的基础上，携带公式【评估是否为异步导出任务】

注：两种方式导出的文件，命名方式以及文件格式均一致。

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35kadwzz2l7E/img/427746ef-61a3-47c5-bebc-e91a2f534696.png?Expires=1787119957&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=zmu4esdrOyKiipLNjFLDxOzDOt0%3D "")

**具体导出表格样式：**

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35kadwzz2l7E/img/1a7b2115-d512-41fe-b088-a452149d5966.png?Expires=1787119957&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=b4HHExYA%2FtINO6iVc3E3f61Fl1o%3D "")
1. 分为10列，表头字段从左到右依次为“资产、行次、期末余额、年初余额、公式、负债和所有者权益、行次、期末余额、年初余额、公式”
2. 关于“资产、行次、期末余额、年初余额、负债和所有者权益、行次、期末余额、年初余额”这8列，取值直接根据资产负债表的系统内容进行取值即可
3. 补充的公式列，需要分别展示每一行次的配置公式，规则如下：
    1. 按照科目进行计算的：**运算符号\+科目编码\+（取数规则）**【示例：\+1001（余额）\+1002（余额）\+1012（借方余额）】![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35kadwzz2l7E/img/2bf773ae-0940-4f2d-9f75-c17794a2b6f4.png?Expires=1787119957&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=8Knp5OVdL56T4oSNGcBPI3GsH8s%3D "")
    2. 按照行次进行计算的：**运算符号\+行次名称**【示例：流动负债合计：】
    3. 若无任何公式，则该行次的公式单元格为空
4. 注：导出时同样携带数据

#### **4.1.2按辅助核算统计**

当在系统参数--全局设置--报表设置，配置了“按科目和辅助核算汇总”后![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35kadwzz2l7E/img/1bfb8542-d771-45f3-9769-443fa8012fcc.png?Expires=1787119957&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=2x1rOHf5jX30kEGYmnwQpQDNj8s%3D "")

在对应的报表中，导出按钮变为下图样式。在原本的导出当前、导出全部下加一个导出公式【相当于导出全部的同时导出公式】

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35kadwzz2l7E/img/60d2f6e2-437a-4ae4-87c8-f959fce5f4c4.png?Expires=1787119957&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=p1qnfO8ISkdHKyQ9KDHgLSEHnPg%3D "")

# **4\. 需求详情**

### **4.1导出明细账**

流水账--核对总账。导出功能调整为，点击后展示“导出总账、导出明细账按钮”

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3JrB4xpgOXo/img/bec5db63-bc97-4215-bd2c-a980178fa046.png?Expires=1787119982&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=UKoyF5QHbUmnJ6zfWdSwayOOOGk%3D "")

导出总账就是原本的导出功能

导出明细账会根据当前的所选期间，对核对总账数据，按照如下格式要求，生成明细账表格

点击后提示判断所有项目是否存在数据，只要有一个项目存在则可以导出，否则提示“暂无数据，无法导出明细”

若可以导出则提示

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3JrB4xpgOXo/img/764cd3dd-393b-46e4-8c09-d5fbbbff3416.png?Expires=1787119982&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=sC0N78fdPVKOQx1PSc6dObvt3xU%3D "")【文件名为：核对总账明细账清单.xls】

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3JrB4xpgOXo/img/0da19429-6a20-4694-8393-c249233627b7.png?Expires=1787119982&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=8Di%2FSAAN9JDA6lRWcHzaE1Ac%2B8Q%3D "")
1. 表格根据导出核对总账时，存在数据的项目进行多个sheet页的拆分。【例如：库存现金存在数据、银行存款没有。则导出时只有库存现金sheet页】【sheet页用项目名下的日记账名来命名】
2. 表头字段：
    1. 明细类型：日记账/总账明细账
    2. 日期：对应日记账/总账明细账的日期
    3. 期初：对应期间日记账的初始余额/明细账的期初余额
    4. 收入（借方发生额）：日记账的收入（借方）/明细账的借方
    5. 支出（贷方发生额）：日记账的支出（贷方）/明细账的贷方
    6. 期末余额：直接取日记账/明细账对应行的余额即可
3. 固定行：
    1. 日记账合计：分别计算日记账类型的期初、收入、支出的相加总和；以及最后一条日记账的期末余额【日期自动取年-月。若有多个期间，则用“、”隔开】
    2. 总账合计：分别计算总账类型的期初、收入、支出的相加总和；以及最后一条总账的期末余额【日期自动取年-月。若有多个期间，则用“、”隔开】
    3. 差额：分别结算期初、收入、支出、余额的值。计算公式为“日记账-总账”

注：列表数据展示，必须要按照日记账/明细账的相同顺序展示，否则余额展示会混乱

- **基础设置 → 科目设置**：现有字段包括科目编码、名称、类别、余额方向、状态、restriction（仅收入科目）

### 0.3 报表公式现状

- 无民间非营利组织会计制度（2026年）（2024年版制度）预置标准公式，业务活动表未区分非限定性/限定性分列
> 本次需求需预置三大报表标准公式。

## 一、快速概览

### 1.1 这个需求要做什么？

**一句话**：新增民间非营利组织会计制度（2026年）（2024年版制度）民非制度账套模板，初始化时自动创建56个标准科目（含子科目和"性质"属性），预置三大报表公式，并更新常用凭证模板和首页取值。

**具体效果**：
- 新建账套时可选择"民间非营利组织会计制度（2026）"-民非制度是2024年版，2026年启用，方便用户理解，统一都显示民间非营利组织会计制度（2026）
- 系统自动生成56个一级科目及全部子科目，收入/费用科目自带"性质"属性
- 三大报表（资产负债表/业务活动表/现金流量表）自动加载标准公式
- 首页看板和常用凭证模板适配新科目编码

### 1.2 谁需要这个功能？

| 角色 | 痛点 | 解决方案 |
|------|------|------------|
| 民非组织财务人员 | 新制度下缺少标准科目体系和报表模板，手工配置繁琐易错 | 选择新制度模板后一键初始化，科目和公式自动就绪 |
| 实施/运维人员 | 客户咨询新版制度支持情况，目前无法提供 | 新增独立制度模板，与旧制度隔离 |

### 1.3 核心价值
- ✅ 符合国家财政部《民间非营利组织会计制度（2026）》合规要求
- ✅ 收入/费用按"非限定性/限定性"区分，结转损益和报表输出更准确
- ✅ 减少客户初始化配置工作量，提升实施效率

## **2.9.3 收入费用结转净资产-边界场景处理**

### **2.9.3.1 费用余额在贷方（负数）**

场景：某费用科目当期贷方余额10,000（如退款/冲销） 处理：结转时记借方10,000，归组规则不变 示例：
```
借：管理费用-非限定性费用（530101）    10,000  ← 负数费用记借方
贷：非限定性净资产（3101）            （差额调整）
```

### **2.9.3.2** **某组合计为零**

场景：非限定性收入150,000，非限定性费用150,000 处理：该组不生成结转凭证

### **2.9.3.3** **限定性收入为零但有限定性费用**

场景：限定性收入0，限定性费用30,000 处理：
```
凭证：结转至限定性净资产
  借：管理费用-限定性费用（530102）    30,000  ← 负数结转
  贷：限定性净资产（3102）             30,000
```
> 限定性净资产减少30,000   



#### 2.9**.4** **结转损益公式（本次需求名称改为“结转净资产”）-“3201 以前年度净资产调整”期末自动结转公式和凭证配置**

### 2.9**.4**.1 结转规则

| 项目 | 规则 |
|------|------|
| 结转时机 | **每期末通过结转净资产功能自动结转** |
| 结转方式 | **系统自动生成结转凭证** |
| 结转逻辑 | 将 3201 各明细科目余额**全额结转**到对应净资产科目 |
| 结转后 | 3201 科目余额清零 |
| 与收入费用结转的区别 | 以前年度净资产调整每期结转凭证不与收入费用结转凭证共用一张凭证，以前年度净资产调整每期结转凭证单独生成一张凭证 |

---

### 2.9**.4**.2 期末自动结转逻辑示例

以前年度非限定性净资产（320101）结转非限定性净资产（3101）处理逻辑

| 当月发生 | 月末余额计算 | 结转方向 |
|-------------------------------------------------------------------------------|-------------------------------------------------------------------------------------|-------------------------------------------------------------------------------|
| 320101贷方发生额 50,000 \+ 320101借方发生额 20,000 | 余额 = 50,000 - 20,000 = 30,000（贷方） | 借：320101 / 贷：3101 |
| 320101贷方发生额 50,000 \+ 320101借方发生额 80,000 | 余额 = 50,000 - 80,000 = -30,000（借方） | 借：3101 / 贷：320101 |

以前年度非限定性净资产（320101）月末余额=本期贷方发生额-本期借方发生额；余额为正结转后科目在借方，余额为负结转后科目在贷方，且分录金额为\+；



以前年度限定性净资产（320102）结转限定性净资产（3102）处理逻辑

| 当月发生 | 月末余额计算 | 结转方向 |
|-------------------------------------------------------------------------------|-------------------------------------------------------------------------------------|-------------------------------------------------------------------------------|
| 320102贷方发生额 50,000 \+ 320102借方发生额 20,000 | 余额 = 50,000 - 20,000 = 30,000（贷方） | 借：320102 / 贷：3102 |
| 320102贷方发生额 50,000 \+ 320102借方发生额 80,000 | 余额 = 50,000 - 80,000 = -30,000（借方） | 借：3102 / 贷：320102 |

以前年度限定性净资产（320102）月末余额=本期贷方发生额-本期借方发生额；余额为正结转后科目在借方，余额为负结转后科目在贷方，且分录金额为\+；

核心规则：系统读取 3201 的期末余额，按余额方向反向一次性转出，不区分借方贷方各发生了几笔。
> 简言之：**3201 余额反向转出，全额进对应净资产。**

```

## 以前年度净资产调整-限定性**结转限定性净资产凭证实例（同期间多笔混合）**

```

### 2.9**.4**.4 关键边界

| 场景 | 处理 |
|------|------|
| 当月借方贷方完全抵消 | 余额 = 0，**不生成**结转凭证 |
| 当月只有借方发生 | 余额在借方，按借方余额结转 |
| 当月只有贷方发生 | 余额在贷方，按贷方余额结转 |
| 当月发生 N 笔借方 \+ M 笔贷方 | 统算余额，**只生成一张**结转凭证 |

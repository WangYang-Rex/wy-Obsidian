# **1\. 需求背景**

现状：

用户针对于已经结账的数据也可以进行复制操作，并且复制出来的日记账数据还关联了相同的记账凭证

目标：

控制已经结账的数据不允许进行复制，且已经结账的期不允许再新增导入

**2\. 业务流程/架构**

# **3\. 功能清单**

| 模块 | 功能点 | 备注 |
|------|---------|------|
| 日记账 | 控制已结账期间，不允许复制和新增导入 |  |
|  |  |  |

# **4\. 需求详情**

### **4.1复制控制**

基础设置-系统参数--做账设置

将流水复制选择“允许一键复制”后

流水账--日记账板块，即会在每一行出现“复制按钮”

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk25NxVz52q4B/img/3f80f537-6628-4354-adf6-21f9ba2038a0.png?Expires=1789461192&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=FrbxwkKsyJ3YTnAPHLUD7S2iG5A%3D "")

具体调整如下：
1. 点击复制时，判断当前日记账的期间是否已经完成结账，若完成则提示“本期已结账，无法复制”
2. 若可以复制时，不再复制凭证这列的内容，其他信息正常复制

注：转账/存取现板块，也同样做改控制（不复制允许复制已结账期间的明细，还有复制时不会复制记账凭证列）

### **4.2新增、编辑、删除控制**

#### **4.2.1日记账板块**

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk25NxVz52q4B/img/6106ea3f-6200-4dce-a82f-6df3f5995e07.png?Expires=1789461192&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=6WGHqAyT5Y8m%2B4YTD%2BtB7AR10h0%3D "")

在日记账板块，对如下操作进行控制：
1. 系统可以正常点击新增按钮，无论自动创建的日期是什么期间。但是在后续系统保存创建对应日记账行数据时（填写收入、支出列数据时）进行判断，当前日记账的日期是否处于已结账期间，
    1. 若不是，则正常创建；
    2. 若是，则提示“已结账期间不允许新增”，并清空当前行的日记账数据
2. 日记账导入时，若导入数据的日期，填写为已结账日期，则视为对应数据导入失败（没问题的正常导入），说明原因“已结账期间不允许新增”![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk25NxVz52q4B/img/221fff19-5b18-4d73-96be-9b3d619f51ec.png?Expires=1789461192&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=U2Z%2Fg%2Fw5gYatyjeou%2BZfHN9PQRw%3D "")注：四种导入方式，均需要补充如上判断
3. 编辑控制就按照目前系统针对于已结账期间数据的已有逻辑处理，不做调整
4. 点击单条删除按钮，判断当前日记账日期所在期间是否已结账。若未结账，再判断是否已经生成凭证或已审核等原始逻辑；若已结账，则直接提示“已结账期间不允许删除日记账”
5. 点击批量删除，判断所选日记账数据的日期是是否存在已结账期间，若存在则更新二次弹窗的展示内容如下“所选日记账中存在【年\+期间、年\+期间】的数据已被结账无法删除，确认是否继续删除其余数据”
    1. 确定：仅删除可以删除的数据
    2. 取消：本次不做删除操作

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk25NxVz52q4B/img/2d53e05e-0d45-4d94-8a02-f4dc16094e43.png?Expires=1789461192&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=fvJIhdo9pRYG0YwYApwA1r3bHJM%3D "")

注：若所有数据均为被结账期间，提示内容相同，但是确定后并不会做删除

注：由于反结账视为未被结账，那么是可以正常新增复制导入的

#### **4.2.2转账/存取现板块**

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk25NxVz52q4B/img/abe81138-2b84-4260-ad9f-a7b092cc75c0.png?Expires=1789461192&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=KanKrLNvUe5u4ATDLJa808eBg3Q%3D "")

由于在转账/存取现板块新增编辑删除后，会同步到日记账板块生响应日记账数据，所以也需要做相应控制
1. 新增：系统可以正常点击新增按钮，无论自动创建的日期是什么期间。但是在后续系统保存创建对应明细行数据时（转出、转入账户以及金额均填写完成时）进行判断，当前日记账的日期是否处于已结账期间
    1. 若不是，则正常创建；
    2. 若是，则提示“已结账期间不允许新增”，并清空当前行的明细数据
2. 编辑：已结账日期的明细数据，不允许修改“日期、转出账户、转入账户、金额、凭证”【直接变为仅读状态即可】
3. 删除：点击单条删除按钮，判断当前明细数据日期所在期间是否已结账。若未结账，再判断是否已经生成凭证以及已审核等原始逻辑；若已结账，则直接提示“已结账期间不允许删除明细”

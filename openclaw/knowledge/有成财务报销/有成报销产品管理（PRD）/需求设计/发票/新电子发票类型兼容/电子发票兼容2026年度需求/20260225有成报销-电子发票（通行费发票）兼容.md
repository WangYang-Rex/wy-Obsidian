# **1\. 需求背景**

<span style="color: rgba(0, 0, 0, 0.9);">发票新规出现：随着全面数字化的电子发票（数电票）推广，通行费发票（高速公路、桥梁、隧道等）已纳入数电票体系；系统中需要兼容新的发票类型，且客户</span>浙江同心母婴要求发票支持对【电子发票（通行费发票）】的归类。

### <span style="color: rgba(0, 0, 0, 0.9);">**二、发票识别：**</span>

<span style="color: rgba(0, 0, 0, 0.9);">发票识别时，调用接口，识别接口中发票类型对应</span><span style="color: rgba(0, 0, 0, 0.9);">数电票(普通发票)</span><span style="color: rgba(0, 0, 0, 0.9);">，在</span><span style="color: rgba(0, 0, 0, 0.9);">数电票(普通发票</span><span style="color: rgba(0, 0, 0, 0.9);">）的返回有通过一个字段去标识是否是</span>【电子发票（通行费发票）】<span style="color: rgba(0, 0, 0, 0.9);">：
"service\_type":表示为通行费标记</span> [<span style="color: #0000FF;"><u>https://console.regenai.com/wiki/fetch/#%E8%BF%94%E5%9B%9E%E5%80%BC</u></span>](https://console.regenai.com/wiki/fetch/#%E8%BF%94%E5%9B%9E%E5%80%BC)

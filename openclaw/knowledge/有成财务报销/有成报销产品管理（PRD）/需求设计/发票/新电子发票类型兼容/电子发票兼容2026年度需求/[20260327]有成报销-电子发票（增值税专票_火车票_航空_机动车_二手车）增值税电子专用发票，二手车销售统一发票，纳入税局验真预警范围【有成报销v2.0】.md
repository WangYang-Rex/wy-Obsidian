## <span style="color: rgba(0, 0, 0, 0.9);">**1\. 需求背景**</span>

### <span style="color: rgba(0, 0, 0, 0.9);">**1.1 需求描述**</span>

<span style="color: rgba(0, 0, 0, 0.9);">将电子发票（火车票）、电子发票（航空运输电子客票行程单）、电子发票（机动车销售统一发票）、电子发票（二手车销售统一发票）</span><span style="color: rgba(0, 0, 0, 0.9); background-color: rgba(16, 24, 40, 0.05);">电子发票（增值税专用发票）</span><span style="color: rgba(0, 0, 0, 0.9);">、增值税电子专用发票、</span><span style="color: rgba(0, 0, 0, 0.9); background-color: rgba(16, 24, 40, 0.05);">二手车统一销售发票</span><span style="color: rgba(0, 0, 0, 0.9);">纳入税局验真范围，确保在开启"税局验真"开关后，上述票种上传时能够正常触发验真预警校验。</span>

### <span style="color: rgba(0, 0, 0, 0.9);">**1.2 需求背景**</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**需求方**</span><span style="color: rgba(0, 0, 0, 0.9);">：财务人员</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**现状问题**</span><span style="color: rgba(0, 0, 0, 0.9);">：
• 客户在基础设置-全局设置-发票设置中开启了"税局验真"开关
• 用户上传电子发票（火车票）和电子发票（航空运输电子客票行程单）时，系统仅完成OCR识别，未触发验真预警
• 电子发票（机动车销售统一发票）、电子发票（二手车销售统一发票）同样存在该问题</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**解决思路**</span><span style="color: rgba(0, 0, 0, 0.9);">：将上述7种电子发票类型加入税局验真逻辑，在全局验真开关开启后自动触发验真预警</span>

<span style="color: rgba(0, 0, 0, 0.9);">**业务流程**</span>
```plain
用户上传问题发票
↓
系统OCR识别发票信息
↓
判断"税局验真"预警开关是否开启
↓
【开启】→ 触发验真预警校验 → 预警禁止/预警提示
【关闭】→ 跳过验真预警 
```

#### <span style="color: rgba(0, 0, 0, 0.9);">**3.2.2 发票上传验真预警触发逻辑**</span>

<span style="color: rgba(0, 0, 0, 0.9);">**功能概述**</span> <span style="color: rgba(0, 0, 0, 0.9);">用户电子发票（火车票）、电子发票（航空运输电子客票行程单）、电子发票（机动车销售统一发票）、电子发票（二手车销售统一发票）</span><span style="color: rgba(0, 0, 0, 0.9); background-color: rgba(16, 24, 40, 0.05);">电子发票（增值税专用发票）</span><span style="color: rgba(0, 0, 0, 0.9);">、增值税电子专用发票、</span><span style="color: rgba(0, 0, 0, 0.9); background-color: rgba(16, 24, 40, 0.05);">二手车统一销售发票</span><span style="color: rgba(0, 0, 0, 0.9);">时，如企业开启了"税局验真"开关，系统自动触发税局验真预警流程。</span>

<span style="color: rgba(0, 0, 0, 0.9);">**业务流程**</span>
```plain
用户上传发票
↓
OCR识别发票信息，税局验真返回验真结果和票面信息
↓
判断"税局验真"开关状态
↓
【开关=ON】
  ↓
  调用预警配置规则
  ↓
  返回验真结果
  ├─ 验真通过 → 发票状态=已验真
  ├─ 验真失败 → 发票状态=验真失败，触发预警规则
  └─ 验真异常 → 发票状态=验真失败，按原逻辑显示失败原因
【开关=OFF】
  ↓
  发票状态=税局验真结果
```

## <span style="color: rgba(0, 0, 0, 0.9);">**附录**</span>

<span style="color: rgba(0, 0, 0, 0.9);">**A. 典型使用场景**</span>

<span style="color: rgba(0, 0, 0, 0.9);">场景：财务开启税局验真预警后，员工上传电子发票（火车票）报销</span>

<span style="color: rgba(0, 0, 0, 0.9);">使用步骤：</span>
1. <span style="color: rgba(0, 0, 0, 0.9);">财务在基础设置-全局设置-发票设置中开启"税局验真"开关，设置预警规则为"预警禁止"</span>
2. <span style="color: rgba(0, 0, 0, 0.9);">员工在报销单中上传电子发票（火车票）</span>
3. <span style="color: rgba(0, 0, 0, 0.9);">系统自动OCR识别发票信息，提取发票号码、日期、金额、校验码</span>
4. <span style="color: rgba(0, 0, 0, 0.9);">系统调用税局验真接口进行验真，并调用“税局验真”预警规则进行判断</span>
5. <span style="color: rgba(0, 0, 0, 0.9);">【验真通过】发票状态变为"已验真"，员工可正常提交报销单</span>
6. <span style="color: rgba(0, 0, 0, 0.9);">【验真失败】发票状态变为"验真失败"，系统阻断提交，提示按系统原逻辑提示</span>

<span style="color: rgba(0, 0, 0, 0.9);">结果：财务可确保所有电子发票（火车票）均经过税局真实性验证，避免虚假发票入账。</span>

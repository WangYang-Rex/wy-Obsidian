## <span style="color: rgba(0, 0, 0, 0.9);">**1\. 需求背景**</span>

### <span style="color: rgba(0, 0, 0, 0.9);">**1.1 需求描述**</span>

<span style="color: rgba(0, 0, 0, 0.9);">为行程组件内的交通工具下拉选择项增加默认选择项配置能力，支持单选模式下默认选中指定选项，减少用户重复选择操作，提升商旅申请单填写效率。</span>

### <span style="color: rgba(0, 0, 0, 0.9);">**1.2 需求背景**</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**需求方**</span><span style="color: rgba(0, 0, 0, 0.9);">：财务管理员、企业员工</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**现状问题**</span><span style="color: rgba(0, 0, 0, 0.9);">：
• 企业内部部分角色用户填写商旅申请单时，频繁添加多个行程
• 每次添加行程时，交通工具选项默认为空，用户需手动选择"不限"
• 用户实际业务场景中，大部分行程交通工具均选择"不限"
• 重复选择相同选项增加操作成本，影响填写效率</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**解决思路**</span><span style="color: rgba(0, 0, 0, 0.9);">：
• 支持在单据模板中配置【行程组件-行程工具】的默认填充规则增加“公式计算”</span>

<span style="color: rgba(0, 0, 0, 0.9);">**业务流程**</span>
```plain
管理员配置单据模板
    ↓
设置行程组件-交通工具字段默认选择项
    ↓
员工填写商旅申请单
    ↓
点击"添加行程"
    ↓
交通工具自动填充默认选项（如"不限"）
    ↓
用户可保留默认或重新选择其他选项
```

## <span style="color: rgba(0, 0, 0, 0.9);">**2\. 功能现状**</span>

<span style="color: rgba(0, 0, 0, 0.9);">**功能位置**</span><span style="color: rgba(0, 0, 0, 0.9);">：基础设置-自定义单据-商旅申请单-行程组件</span>

<span style="color: rgba(0, 0, 0, 0.9);">**现有字段**</span><span style="color: rgba(0, 0, 0, 0.9);">：
• 行程日期（出发日期、返回日期）
• 出发地/目的地（城市选择）
• 交通工具（下拉选择：不限/飞机/火车/酒店/用车等）-不限选项仅为携程商旅生效
• 舱位等级（关联交通工具动态显示）
• 行程备注</span>

<span style="color: rgba(0, 0, 0, 0.9);">**现有操作**</span><span style="color: rgba(0, 0, 0, 0.9);">：
• 单据模板可配置行程组件显示/隐藏
• 交通工具字段可配置选项内容
• 交通工具字段可开启多选功能（默认单选）</span> <span style="color: rgba(0, 0, 0, 0.9);">• 员工填写时每次添加行程需手动选择交通工具</span>

<span style="color: rgba(0, 0, 0, 0.9);">• "不限"选项仅对携程商旅申请单有效</span>

<span style="color: rgba(0, 0, 0, 0.9);">**缺失能力**</span><span style="color: rgba(0, 0, 0, 0.9);">：
• 不支持配置交通工具默认选择项
• 行程组件-行程工具缺少默认填充规则-公式计算项配置</span>

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45K56zv9DqDQ/img/a9cc293b-5554-42f7-aac7-26c9172133d5.png?Expires=1786515692&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=pNdrQL9w8KTK5Fkp91fA9ojGXU0%3D "")



<span style="color: rgba(0, 0, 0, 0.9);">**填充逻辑**</span>
```plain
用户点击【添加行程】
    ↓
系统读取单据模板配置
    ↓
判断交通工具字段默认选择项配置
    ↓
IF 默认选择项不为空 THEN
    自动填充默认选项到交通工具字段
ELSE
    交通工具字段为空（保持现有逻辑）
END IF
    ↓
用户可手动修改已填充的选项
```

## <span style="color: rgba(0, 0, 0, 0.9);">**附录**</span>

<span style="color: rgba(0, 0, 0, 0.9);">**A. 典型使用场景**</span>

<span style="color: rgba(0, 0, 0, 0.9);">**场景：销售团队频繁提交差旅申请**</span>

<span style="color: rgba(0, 0, 0, 0.9);">背景：
• 公司销售团队经常出差拜访客户
• 每次出差需填写商旅申请单，包含多个行程（去程、返程）
• 大部分行程对交通工具无特殊要求，均选择"不限"
• 目前每次添加行程都需手动选择"不限"，操作繁琐</span>

<span style="color: rgba(0, 0, 0, 0.9);">配置步骤（管理员）：</span>
1. <span style="color: rgba(0, 0, 0, 0.9);">财务管理员进入【基础设置-自定义单据-商旅申请单】</span>
2. <span style="color: rgba(0, 0, 0, 0.9);">点击行程组件的【字段设置】</span>
3. <span style="color: rgba(0, 0, 0, 0.9);">在"默认选择项-公式计算"区域配置"不限"作为默认值</span>
4. <span style="color: rgba(0, 0, 0, 0.9);">保存模板配置</span>

<span style="color: rgba(0, 0, 0, 0.9);">使用步骤（员工）：</span>
1. <span style="color: rgba(0, 0, 0, 0.9);">销售员工创建新商旅申请单</span>
2. <span style="color: rgba(0, 0, 0, 0.9);">点击【添加行程】</span>
3. <span style="color: rgba(0, 0, 0, 0.9);">系统自动填充交通工具为"不限"</span>
4. <span style="color: rgba(0, 0, 0, 0.9);">员工只需填写出发地、目的地、日期等信息</span>
5. <span style="color: rgba(0, 0, 0, 0.9);">如需指定交通工具，点击"不限"重新选择即可</span>

<span style="color: rgba(0, 0, 0, 0.9);">结果：销售员工每次添加行程无需手动选择交通工具，填写效率提升约30%。</span>

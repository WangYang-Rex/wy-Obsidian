## 一、需求背景

### 需求现状：

客户在单据详情内查看火车票的消费明细信息时看不到火车票的消费的"乘车人"字段；

### 客户预期：
1. 自定义费用-xx费用-文本组件可设置"公式计算"-规则编辑器-添加字段-当前费用字段-**发票下字段**，确保该文本组件可取到单据内发票详情上的信息；
2. 将该文本组件保存为常用字段
3. 单据详情内的消费明细组件上通过字段显示功能搜索乘车人（常用文本组件）设置为显示，则用户可在消费明细组件中看到乘车人字段列

## 三、功能需求

### 3.1 公式编辑器-当前费用字段新增"发票"可选字段信息

**流程**：自定义费用 → xx费用 → 添加xx组件 → 设置公式计算 → 规则编辑器 → 添加字段 → 当前费用字段 → 发票（新增） 

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZJeKX6zqxA/img/32138ae1-89f9-4be8-ae1f-b3b2f89f75d3.png?Expires=1784207380&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=O2M%2B2rKXXOAC7nNZSTPRkAEhWy8%3D "")

**功能描述**：
- 在规则编辑器的"添加字段"弹窗中，"当前费用字段"下新增一级分组"发票"
- "发票"分组下新增字段"购方名称""销方名称""乘车人"为**文本数组**
- 用户选择"发票"下字段后，该字段可参与公式编辑，取值来源为当前费用内发票详情中的信息
- 示例-“乘车人”取发票详情中火车票的“乘车人”
- 展示逻辑按系统已有的字段展示规则执行，本次不改动













### 研发无需看-本次需求客户要求实现效果-使用描述-消费明细-字段显示增加乘车人

**流程**：自定义费用 → xx费用 → 添加文本组件 → 公式计算引用发票-乘车人 → 保存为常用字段 → 单据详情消费明细 → 字段显示 → 搜索乘车人 → 勾选显示

**位置**：单据详情 → 消费明细 → 字段显示

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZJeKX6zqxA/img/6fa3fea0-b3d2-43b6-ba31-3233f89447dd.png?Expires=1784207380&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=%2B%2B2rzJBhJ6AeDeIF8Pw7BWk6ltM%3D "")

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZJeKX6zqxA/img/01c0ab59-3255-48da-95ee-9340160977a0.png?Expires=1784207380&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=Xb5PVswrsscmeWKqdAoNfqMTGR8%3D "")

**功能描述**：
- 用户将引用了"发票-乘车人"的文本组件保存为常用字段后，该字段出现在消费明细的字段显示可选列表中
- 字段显示增加"乘车人"选项
- 勾选后按顺序显示在消费明细列表内，无数据时为空

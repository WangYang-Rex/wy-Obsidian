# **1\. 需求背景**

账户设置：

目前存在创建的字数限制，上线10个字符，现在需要拓展字数上限，用户存在超出10个字符的情况

# **2\. 业务流程/架构**

# **3\. 功能清单**

| 基础设置 | 账户设置-账户名称字符限制改为30个字符 |  |

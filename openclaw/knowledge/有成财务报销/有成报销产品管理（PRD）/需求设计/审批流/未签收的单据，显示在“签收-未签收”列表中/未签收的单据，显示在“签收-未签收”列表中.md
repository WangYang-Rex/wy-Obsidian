# 未签收的单据，显示在“签收-未签收”列表中

| **修订时间** | **版本** | **编写人** | **修订说明** |
|----------------|----------|-------------|----------------|
| 20230426 | v1.0 | 小乔 | 新建 |

## 1、需求背景

现状：<span style="color: #1D1D1F;">审批流在某个节点设置了”签收“，流转到该节点时，会生成一个签收任务（签收-未签收列表有一条数据），当该节点审批完成后，即使未签收，这个签收任务就没有了</span>

<span style="color: #1D1D1F;">客户诉求：对于用户来说，有些单据会在审批完之后再进行签收，希望能在未签收中找到这个单据</span>

## 2、业务流程/架构

## 3、功能清单

根据个人需要补充

| **模块** | **功能点** | **备注** |
|----------|-------------|----------|
| 签收-待签收 | 显示所有需要签收，未被签收的单据数据 |  |
|  |  |  |
|  |  |  |

### 4.1、系统【有成报销】PC & MB

### 4.2、签收-待签收列表

审批节点配置了签收，审批完成后，签收任务依然保留在待签收列表

<span style="color: #E4495B;">单据驳回/删除时，列表中签收任务单据数据也对应删除</span>

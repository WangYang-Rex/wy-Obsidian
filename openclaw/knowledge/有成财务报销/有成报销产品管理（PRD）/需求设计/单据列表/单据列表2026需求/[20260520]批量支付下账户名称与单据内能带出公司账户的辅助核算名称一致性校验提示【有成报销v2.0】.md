## 一、需求背景

### 需求现状

客户在辅助核算类别模版-表单编辑中添加了公司账户组件，并给该辅助核算类别下的辅助核算项维护了公司银行账户，后续客户填写单据时选择该辅助核算类别的辅助核算项，就可以判断出该单据跟哪个公司有关且跟公司下哪个银行账户有关；单张单据走到审批的确认支付界面时，出纳选择支付账户时只能选择到所选辅助核算项带出的公司账户作为支付账户；只是多选单据进行批量支付时，还是选择一个账户批量支付，但是单据内存在多个不同能带出公司账户的辅助核算项；

### 客户预期

点击"确认"批量支付后，若批量勾选的单据内包含多个辅助核算能带出不同的公司账户信息的账户与后续所选支付银行账户存在任一不一致时，弹出确认提示告知出纳，确认后方可继续支付。

## 三、功能需求

### 3.1 批量支付-辅助核算公司账户与所选支付账户一致性校验与提示

**流程**：批量勾选待支付单据 → 点击"支付" → 弹出确认支付弹窗 → 选择支付账户 → 点击"确认" → 系统校验 → 存在不一致时弹出确认提示 → 确认/取消 → 继续支付/返回

**位置**：待办 → 审批 → 待支付 → 批量支付

**功能描述**：
- 在批量支付流程中，用户在确认支付弹窗内选择支付账户后点击"确认"，系统执行一致性校验
- **仅批量支付触发此校验**，单张单据支付不触发（单张支付保持原有的账户限制选择逻辑）
- 校验范围：遍历所有勾选单据，提取每张单据中**绑定了公司账户组件的辅助核算类别**下的辅助核算项所带出的公司账户ID
- 校验逻辑：将所有勾选单据中满足条件的辅助核算项所带出的**公司账户ID**，与出纳所选的支付银行账户ID进行比对
- 辅助核算项绑定的公司账户值为空时，该单据不参与比对，视为无冲突
- 单据未配置辅助核算组件，同上，视为无冲突，不参与比对
- 单据配置了辅助核算，但该辅助类别未绑定公司账户组件，同上，视为无冲突，不参与比对
- 触发条件：若任意一张单据的辅助核算公司账户ID中，没有与所选支付账户ID匹配的记录，则弹出确认提示
- 部分单据匹配、部分不匹配：仍触发提示（只要存在任一不一致即提示）
- 提示文案："部分单据的辅助核算公司账户与所选支付账户不一致，是否继续支付？"
- 提示为软提示，用户点击"确定"关闭弹窗，继续执行批量支付
- 用户点击"取消"关闭弹窗，留在当前确认支付页面，不执行支付
- 若所有满足校验条件的辅助核算公司账户ID均与所选支付账户ID一致，不弹提示，直接执行支付

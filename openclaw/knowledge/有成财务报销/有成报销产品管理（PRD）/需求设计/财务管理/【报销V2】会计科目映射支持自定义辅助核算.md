# **1\. 需求背景**

现状：

客户存在用到多个辅助核算的场景，因为需要用不同的辅助核算来控制费用进入哪个科目，而常用辅助核算只能选择一次，所以只能选择自定义辅助核算字段。

解决方案：

会计科目映射支持按照分摊的自定义辅助核算字段作为条件，区分科目

# **3\. 功能清单**

|------|---------|------|

# **4\. 需求详情**

### **4.1会计科目映射**

**梳理现有逻辑：**

用户在自定义单据中维护了【常用/自定义辅助核算】，那么在填写消费明细的费用分摊时，就可以维护相应的辅助核算字段内容，但是关于映射配置分为两种情况：![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35oB5gAr9l7E/img/f581f91c-1ecb-45d2-a1eb-0207fffa831a.png?Expires=1784207205&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=FkU4rk6byIGNDfXsC0zKTbQ95Lk%3D "")
1. 维护的是常用辅助核算：需要在配置时选择“辅助核算（费用）”来进行映射，才会根据分摊时的不同辅助核算，进入不同的科目【目前已满足】![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35oB5gAr9l7E/img/8f02ef13-84bc-4b28-9c30-0bf3b70d1e47.png?Expires=1784207205&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=hQwZkh1God5y%2FP%2BoZFaiA49ku10%3D "")
2. 维护的是自定义辅助核算：目前无法实现会计科目映射

**解决方案：**
1. 为了可以在后续会计科目映射时配置，需要将单据内自定义辅助核算字段保存为常用字段。![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35oB5gAr9l7E/img/eaf58279-5ae6-4cfe-9670-ec6de72bae51.png?Expires=1784207205&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=stCzEkfgOYCdk6MGHoNcnEPFtw0%3D "")
2. 根据优先级来处理映射规则**【开发新增逻辑】**
    1. 优先取单据消费明细下的费用分摊处的自定义常用字段来进行会计科目映射匹配![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35oB5gAr9l7E/img/02668afa-4e22-4534-be8a-16a69a92c601.png?Expires=1784207205&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=sbZKjqlp%2BwDWthyew2xcmfbakGk%3D "")
    2. 其次再取单据上的自定义常用字段来进行会计科目映射匹配![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35oB5gAr9l7E/img/57ad4988-5367-4027-9142-92d7748e00a6.png?Expires=1784207205&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=xCn0jUUMZozCWiLjrLqr6ey5n3o%3D "")
    3. 若均未填写才会视为找不到相应的科目

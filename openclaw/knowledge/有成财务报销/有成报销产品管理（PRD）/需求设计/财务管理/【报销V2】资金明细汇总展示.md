# **1\. 需求背景**

现状：

目前的资金明细进入后就是默认会展示某一个账户下的相应明细信息，用户如果想要做查看需要反复切换，比较麻烦

解决方案：

默认进入汇总资金明细展示页面，对数据进行全局查看包括统计数据

# **4\. 需求详情**

### **4.1**资金明细汇总展示

系统新增全部账户的交互样式，用户在进入时到底是展示全部账户还是单独账户，还是保留目前的记录逻辑，根据上次操作后所在的账户来进行展示

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45K6BVMExqDQ/img/1989ed58-792e-4a44-8280-add04480eb85.png?Expires=1784207206&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=DztI5dnuNYTuCdv6yQojBCq3Ihk%3D "")

当处于全部账户时，页面交互：
1. 左上角不再展示单独的相应账户，而是展示“全部账户”。隐藏账户名、银行卡号、开户行信息
2. 下方列表多展示两个字段“账户名、银行卡号”。即汇总展示所有账户下的交易明细
3. 余额、昨日收入、昨日支出、交易总金额、支出金额、收入金额。这六个统计字段，需要汇总所有账户下数据来展示，而非只展示单一账户信息
4. 其余按钮、过滤条件等功能无任何调整变动

注：汇总展示的账户也需要按照权限来展示，不能汇总权限外的账户

![image.png](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45K6BVMExqDQ/img/2f5b5d9e-330c-419a-a5cd-e1f431c5e20a.png?Expires=1784207206&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=MJ9Ts6LIHJOlcJoaiCM4TbDwxMI%3D "")

当点击切换账号，切换为单一账户时，交互样式变为原样式，列表字段、统计数据都恢复原逻辑。在此基础上加一个按钮“汇总展示”。点击切换为汇总展示效果

注：开发评估需要调整“搜索、刷新数据、下载全部回单、获取历史回单”四个接口，因为接口会涉及到账户id，需要改为，当切换到汇总展示时，这四个接口需要传所有有权限的账户id

特殊情况：如果出现某一账户的接口异常导致在汇总展示时无法正常处理，那么需要做如下控制：
1. 统计：如果某一账户异常，需要重试处理，直到可以完整取数或达到重试上限后报错“【账户名】账户统计异常，请逐个账户查看”
2. 下载全部回单：某一账户异常，则操作后提示如下弹窗

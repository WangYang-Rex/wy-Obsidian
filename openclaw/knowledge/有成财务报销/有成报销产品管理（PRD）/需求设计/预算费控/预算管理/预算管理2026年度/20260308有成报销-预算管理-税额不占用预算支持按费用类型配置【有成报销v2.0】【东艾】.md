# <span style="color: rgba(0, 0, 0, 0.9);">**1\. 需求背景**</span>

## <span style="color: rgba(0, 0, 0, 0.9);">**1.1 目标用户**</span>

<span style="color: rgba(0, 0, 0, 0.9);">财务管理员、预算管理员</span>

## <span style="color: rgba(0, 0, 0, 0.9);">**1.2 需求来源**</span>

<span style="color: rgba(0, 0, 0, 0.9);">东艾科尖端薄膜（南通）有限公司客户</span>

## <span style="color: rgba(0, 0, 0, 0.9);">**1.3 背景**</span>

### <span style="color: rgba(0, 0, 0, 0.9);">**1.3.1 现有功能说明**</span>

<span style="color: rgba(0, 0, 0, 0.9);">有成报销目前支持自定义费用模版中加入税率税额组件，有税率税额组件的单据业务逻辑如下：</span>
```plain
有成单据
    └── 费用明细组件
            └── 添加费用类型（支持自定义），含税率税额组件
                    └── 上传发票
                            ├── 识别发票信息
                            ├── 计算发票金额
                            └── 计算税额
```


```plain
有成单据
    └── 含税率税额组件     
       └── 上传发票
       ├── 识别发票信息
       ├── 计算发票金额
       └── 计算税额
```



### <span style="color: rgba(0, 0, 0, 0.9);">**1.3.2 预算管理现状**</span>

<span style="color: rgba(0, 0, 0, 0.9);">预算管理中已支持"税额不占用预算"功能，即某些类型的发票税额可以不占用预算额度。当前配置方式为：</span>
- <span style="color: rgba(0, 0, 0, 0.9);">在预算管理-基础设置中配置"不占预算发票"类型</span>
- <span style="color: rgba(0, 0, 0, 0.9);">支持按发票属性（如增值税专用发票、普通发票等），发票类别进行配置</span>
- <span style="color: rgba(0, 0, 0, 0.9);">配置后，符合条件的报销单/付款单中的发票税额不计入预算占用</span>

### <span style="color: rgba(0, 0, 0, 0.9);">**1.3.3 客户业务场景**</span>

<span style="color: rgba(0, 0, 0, 0.9);">东艾科公司的业务特点：</span>
1. <span style="color: rgba(0, 0, 0, 0.9);">**多费用类型管理**</span><span style="color: rgba(0, 0, 0, 0.9);">：公司内部定义了多种费用类型（如差旅费、招待费、办公费、材料费等）</span>
2. <span style="color: rgba(0, 0, 0, 0.9);">**差异化预算管控需求**</span><span style="color: rgba(0, 0, 0, 0.9);">：不同类型的费用，其发票税额是否占用预算有不同的管理要求</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">差旅费、招待费：税额需要占用预算</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">材料费、设备采购费：税额不占用预算</span>
3. <span style="color: rgba(0, 0, 0, 0.9);">**自定义费用类型**</span><span style="color: rgba(0, 0, 0, 0.9);">：有成报销支持自定义费用类型</span>
4. <span style="color: #FE0300;">**特殊业务场景：**</span><span style="color: #FE0300;">设置了增值税发票税额不占用预算配置，但</span><span style="color: #FE0300;">涉及进项税转出的费用类型，即使上传了增值税发票，税额需要占用预算</span>

## <span style="color: rgba(0, 0, 0, 0.9);">**1.4 核心痛点**</span>

### <span style="color: #FE0300;">**痛点：无法按发票类别与费用类型维度组合配置税额不占用预算**</span>

<span style="color: #FE0300;">**现状**</span><span style="color: #FE0300;">：现有功能仅支持按发票类型配置，不支持按"费用类型"维度组合</span>

<span style="color: #FE0300;">**影响**</span><span style="color: #FE0300;">：无法满足"涉及进项税转出的费用类型下的增值税发票税额占用预算，其余费用类型喜爱的增值税发票税额不占用预算"的精细化管理需求</span>

# <span style="color: rgba(0, 0, 0, 0.9);">**2\. 业务流程/架构**</span>

## <span style="color: rgba(0, 0, 0, 0.9);">**2.1 业务流程图**</span>


```plain
┌─────────────────────────────────────────────────────────────────────┐
│                    税额不占用预算-费用类型配置流程                     │
├─────────────────────────────────────────────────────────────────────┤
│  财务管理员进入预算管理-基础设置                                      │
│       ↓                                                             │
│  选择"税额不占用预算"配置项                                          │
│       ↓                                                             │
│  ┌─────────────────────────────────────────────────────────────┐   │
```

## <span style="color: rgba(0, 0, 0, 0.9);">**2.2 单据内费用类型预算占用计算流程**</span>

<span style="color: rgba(0, 0, 0, 0.9);">**现有逻辑：**</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**单据内有消费明细组件且消费明细内配置了税率税额组件，优先从此处取发票税额；**</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**单据内仅有税率税额组件，从此处取发票税额；-当前仅付款单类型单据可在单据内配置税率税额组件**</span>
- <span style="color: rgba(0, 0, 0, 0.9);">**单据内无消费明细也无税率税额组件，取不到税额**</span>
```plain
单据提交时
    ↓
遍历费用明细组件中的每一行
    ↓
对于每个费用明细：
    1. 获取费用类型
    2. 获取发票金额、税额
    3. 查询税额不占用预算配置
       IF 费用类型在配置列表中 THEN
           预算占用金额 = 消费金额 - 税额（不含税金额）
       ELSE
           预算占用金额 = 消费金额（含税金额）
       END IF
    4. 累计该明细的预算占用金额
    ↓
汇总所有明细的预算占用金额
```



前置条件：
- 付款单据和借款单据内允许直接配置税率税额组件，且同时费用类型和金额组件
```plain
单据提交时
    ↓
找到单据内税率税额组件，费用类型组件和金额组件
    ↓
    1. 获取费用类型
    2. 获取单据金额、税额
    3. 查询税额不占用预算配置
       IF 费用类型在配置列表中 THEN
           预算占用金额 = 单据金额 - 税额（不含税金额）
       ELSE
           预算占用金额 = 单据金额（含税金额）
       END IF
```

1. <span style="color: rgba(0, 0, 0, 0.9);">**功能入口：**</span><span style="color: rgba(0, 0, 0, 0.9);">预算费控-预算管理-基础设置-预算结转-手工结转规则-设置结转比例-配置预算维度</span>
2. <span style="color: rgba(0, 0, 0, 0.9);">**核心功能：**</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">预算维度选择组件由单选/逐一点击改为节点树多选组件</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">支持父子节点联动：通过父节点点击【全选】文字按钮自动全选末级节点，点击【取消全选】父节点自动取消所有末级节点</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">支持某根节点下末级节点部分选中时，父节点至根节点显示【全选】文字按钮</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">支持某根节点下末级节点全部被选中时，父节点至根节点显示【取消全选】文字按钮</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">节点树支持搜索筛选，快速定位目标维度</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">已选维度在选择框内显示</span>
3. <span style="color: rgba(0, 0, 0, 0.9);">**默认策略：**</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">默认不选中任何维度节点</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">展开一级节点，二级及以下节点折叠</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">搜索时自动展开匹配节点路径</span>
4. <span style="color: rgba(0, 0, 0, 0.9);">**存储方案：**</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">参照【预算结转规则】已有存储方案逻辑</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">保存时存储选中的末级维度节点ID列表</span>
5. <span style="color: rgba(0, 0, 0, 0.9);">**存量兼容：**</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">存量规则配置保持原有维度选择不变</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">编辑时原有已选维度正常回显</span>
    - <span style="color: rgba(0, 0, 0, 0.9);">新功能仅优化选择交互，不影响数据存储结构</span>
